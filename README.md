# 📚 도서 수호자 (Book Guardian)

> YES24 도서 데이터 기반 AI 도서 추천 + 유튜브 플레이리스트 추천 데스크탑 애플리케이션


## 주요 기능

- 책 이름 · ISBN · 키워드 · 작가 · 국가 · 장르 복합 검색 및 자동완성
- TF-IDF 코사인 유사도 기반 도서 추천 및 유사 도서 5권 표시
- 장르 매칭 기반 유튜브 플레이리스트 10개 추천
- yt-dlp를 활용한 장르별 플레이리스트 자동 수집

## 화면 구성
 
```
recommend_system.py        ← 메인 실행 파일
├── 검색 입력 (책 이름 / ISBN / 키워드 / 작가 / 국가 / 장르)
├── 검색 결과 카드 리스트
│   └── 카드 클릭 → 상세 패널 토글
│       ├── 책 소개 (원본 설명)
│       ├── 이 책과 비슷한 책 (유사도 Top 5)
│       └── [♪ 추천 플레이리스트] 버튼
│           └── PlaylistRecommendApp 팝업
│               └── 장르별 플레이리스트 목록 + ▶ 재생
```

## AI 추천 모델

### TF-IDF 기반 도서 추천

- `tfidf_total.pkl` — TfidfVectorizer (vocab: 26,463)
- `Tfidf_book_total.mtx` — 전체 도서 희소행렬 (4,938 × 26,463)

**키워드 재정렬:** 입력 키워드 → TF-IDF 벡터 변환 → 검색 결과와 코사인 유사도 계산 → 내림차순 정렬

**유사 도서 추천:** 선택한 책의 TF-IDF 벡터 → 전체 도서와 코사인 유사도 → 상위 5권 반환

### 플레이리스트 추천

1. 책 장르 → `playlist_all.csv` genre 컬럼 매핑
2. 장르 일치 항목 우선 배치
3. 책 제목 첫 단어가 플레이리스트 title에 포함되면 추가 가중치
4. 최대 10개 반환
